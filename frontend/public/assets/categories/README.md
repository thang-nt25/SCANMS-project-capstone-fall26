# Category icon artwork

Generated with the built-in image_gen tool for SCANMS category navigation. These are generic category illustrations, not photographs of listed inventory or Shopee assets. Final PNG assets are resized to 256 × 256 for delivery.

Shared prompt: Square ecommerce category photographic icon; realistic miniature studio object photography, isolated centered object cluster on white, full objects visible, generous margins, restrained shadow, readable at 80px. No text, letters, logos, labels, watermark, border, UI or pedestal.

Subjects:
- skin-v1.png: Amber serum dropper bottle and white cream jar.
- makeup-v1.png: Coral lipstick, neutral eyeshadow compact and makeup brush.
- body-v1.png: Ivory shampoo pump bottle, hair comb and folded towel.
- health-v1.png: White vitamin bottle with gold cap, capsules and small leaf.

CategoryQuickNav uses fixed artwork and shows a category only when the loaded catalog has matching products. The original generation files remain under the Codex generated_images directory.
