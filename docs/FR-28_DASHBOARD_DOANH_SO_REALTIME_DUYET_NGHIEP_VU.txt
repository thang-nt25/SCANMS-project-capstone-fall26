2. DANH SÁCH API ENDPOINTS BACKEND (/api/dashboard/realtime-*)
----------------------------------------------------------------------------------------------------
1. GET /api/dashboard/realtime-overview
   - Mô tả: Trả về 5 thẻ chỉ số KPI tổng quan (Tổng Doanh Thu GMV, Đơn Hàng Thành Công, Tỷ Lệ Chuyển Đổi %, Tổng Hoa Hồng, Lượt Clicks) kèm % so sánh tăng trưởng so với kỳ trước.
   - Hỗ trợ bộ lọc: timeRange (today, 7d, 30d, this_month, custom), startDate, endDate, storeId, collaboratorId.

2. GET /api/dashboard/realtime-timeseries
   - Mô tả: Trả về chuỗi dữ liệu biểu đồ phân tích theo thời gian (giờ nếu xem 'today', ngày nếu xem khoảng thời gian dài).
   - Dữ liệu từng mốc: timestamp, date/hour, revenue, orders, clicks, commission, conversionRate.

3. GET /api/dashboard/realtime-top-products
   - Mô tả: Trả về Top 5 - 10 sản phẩm bán chạy nhất, bao gồm số lượng bán, tổng doanh thu tạo ra, hoa hồng và tỷ lệ đóng góp doanh thu %.

4. GET /api/dashboard/realtime-top-channels
   - Mô tả: Phân bổ lưu lượng & đơn hàng theo kênh (TIKTOK, FACEBOOK, INSTAGRAM, YOUTUBE, DIRECT / OTHER) kèm doanh thu và tỷ lệ % thị phần.

5. GET /api/dashboard/realtime-funnel
   - Mô tả: Phễu chuyển đổi 3 cấp độ:
     + Lượt nhấp chuột (Clicks) -> 100%
     + Đơn hàng khởi tạo (Initiated Orders)
     + Đơn hàng thành công (Paid / Delivered Orders) -> Tính % chuyển đổi cuối (End-to-End Conversion Rate).

6. GET /api/dashboard/realtime-campaign-performance
   - Mô tả: Thống kê hiệu năng các chiến dịch VIP Campaign (tích hợp trực tiếp với FR-27), bao gồm: Số lượng KOL tham gia, Đơn hàng sinh ra qua link chiến dịch, Doanh thu chiến dịch, Hoa hồng & Thưởng thêm (Bonus Rate) đã chi trả.
